### <a name="_bjrr7veeh80c"></a>**Альтернативы**
Опишите здесь наиболее важные альтернативные решения.

Альтернатива 1: Единый REST API для всех кол-центров

Описание: Предоставить партнерскому кол-центру доступ к REST API Сервиса ставок

Недостатки: Нарушает требование о файловом обмене. Требует изменения архитектуры партнерской системы, что невозможно по условиям.

Альтернатива 2: Репликация базы данных ставок

Описание: Настроить репликацию базы данных ставок в систему кол-центра

Недостатки: Избыточная сложность, проблемы с безопасностью, нарушение границ контекстов

**Недостатки, ограничения, риски**
